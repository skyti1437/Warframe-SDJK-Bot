## 一、Forma 与极化（Polarization）

### Forma：游戏内描述原文

> 「这个非固定形态的零件是奥罗金时代建筑中不可或缺的。**可以改变战甲、同伴或武器的极性槽，并将等级重置为无等级。只能用于满级的战甲、同伴及武器。**」
> —— 游戏内描述（In-Game Description）

- **类型**：资源（Resource）
- **不可交易**（Untradeable）、**不可出售**（Cannot Sell）
- **引入版本**：Update 8.0（2013-05-23）

### Forma 的两个用途

1. **主用途**：作为**超级强化器（supercharger）**，为战甲 / Archwing / 武器 / 同伴的**某个 Mod 槽位添加、移除或改变极性**。此过程称为**极化（Polarization）**，目的是让 Mod 容量被更高效地使用。
2. **次用途**：
   - 作为**制作材料**：武器蓝图、Exilus Warframe Adapter、其他超充能装备、氏族道场地板（Tiles）
   - 可**献祭**以提升集团（Syndicate）声望等级

### 极化（Polarization）：完整机制

**定义**：极化是向武器 / 同伴 / 战甲的 Mod 槽位**添加或修改极性**的过程，让单件装备能装更多 Mod，从而把战力提升到超出原始容量。

**操作前提**：**装备必须达到 Rank 30（满级）**，极化选项才会出现。

**操作步骤**：
1. 应用 Forma
2. 选择一个 Mod 槽位进行极化（可多次点击槽位循环切换不同极性，**已带极性的槽位也可以改**）
3. 点击「Apply」

### ★ 极化的后果（最常被答错的一点）

- **极化会把装备等级重置为 0 级**，需要**重新升级**。
  - 原文：`Polarizing will reset the equipment to rank 0 and it will have to be leveled again.`
  - 游戏内描述原文：`resets their affinity to Unranked`
- **重新升级不会再次给予段位经验（Mastery Points）。**
- **不会**移除装备上已装的 Orokin Catalyst / Orokin Reactor / Focus Lens；但**在重新练到满级前不会产生专精（Focus）**。
- 极化过的 Warframe / Archwing / 战甲可自定义**副能量色**（Secondary Energy Color）。

### ★ 常见误解（否定事实）

- **极化不会给你「额外的 Mod 槽位」。** 它只改变**已有**槽位的极性符号，槽位数量不变。
- **不存在「极化等级」这个概念。** 游戏里没有"极化等级""极化核心""极化符文"这类物品或数值。装备上用掉的 Forma 数量只以小星标显示在升级菜单顶部（名字与等级右侧），**不是可累积的等级**。
- **极化不影响基础属性（生命/护盾/护甲/能量）。** 它只影响 Mod 容量效率。
- **极化不可逆且不退款**：Forma 无法返还；要取消或改动极化，必须**再走一遍流程并再消耗一个 Forma**（已极化的槽位也可以"去极化"，但 Forma 照样消耗）。

### 与段位（Mastery Rank）的联动

- 极化 **Warframe / Archwing / 殁世机甲** 后，**技能解锁状态**会按玩家的段位保留（但**属性仍重置为 0 级**）：
  - 段位 10：极化后 0 级即有全部技能解锁
  - 段位 20：全部技能解锁，第 1 技能 3 级、其余 1 级
  - 段位 30：全部技能解锁且均为 3 级
- 段位 30+ 的玩家若给战甲装过至少 1 个 Forma，可在突击与仲裁中**跳过「30 级战甲」要求**。
- **段位影响的是"技能是否被锁"，不影响属性数值**（属性照样回到 0 级）。

### Forma 的所有变体

| 变体 | 作用 |
|---|---|
| **Omni Forma（全能 Forma）** | 唯一能添加**万能极性（Universal）**的方式 |
| **Umbra Forma（暗影 Forma）** | 唯一能添加 **Umbra 极性**的方式 |
| **Stance Forma（架式 Forma）** | 用于给**近战武器的架式槽（Stance Slot）**设置极性（也可让光环槽受益） |
| **Aura Forma（光环 Forma）** | 用于**光环槽（Aura Slot）**的极性设置 |
| **TEST FORMA** | 测试用物品，非正常获取 |

> ⚠️ **Umbra 极性只能用 Umbra Forma 添加**；**万能极性只能用 Omni Forma 添加**——普通 Forma 做不到这两件事。

### Forma 的获取途径

- **蓝图**来自特定**遗物（Relics）**：Common 掉 1 个、Uncommon 掉 2 个
- **Acrithis 商店**：10 Pathos Clamps 买蓝图
- **每日献礼（Daily Tribute）**可得蓝图
- **Zariman Ten Zero / 虚空 / Lua** 的稀有或加固储物容器极小概率掉落（**Lua 音乐谜题保证出一个稀有储物容器**）
- 有时可从 **1999 日历**获得
- **Teshin（钢铁之路 Honors 商店）**：以钢铁精华购买**三合一 Forma 捆绑包**（按 8 周轮换）
- **午夜电波（Nightwave）**特定等级奖励三合一捆绑包
- **商城**：成品 20 铂金；三合一捆绑包 35 铂金
- **行动：瘟疫之星**期间可在 Cetus 的 Nakak 处用行动补给声望 3000 + 5000 现金购买
- **制作**：Forma ×1｜神经元 ×1｜赤毒（或对应材料）等（Umbra Forma 需 Forma ×1｜神经元 ×1｜赤毒 ×500｜纳米孢子 ×1100，建造 24 小时）

> **来源**：`wiki.warframe.com/w/Forma`、`wiki.warframe.com/w/Polarization`

## 二、极性（Polarity）与 Mod 容量

### 极性的作用

**极性决定 Mod 装入对应槽位时的容量消耗**：

- **极性匹配**：该 Mod 的容量消耗 **减半（÷2）**
- **极性不匹配**：该 Mod 的容量消耗 **翻倍（×2）**

> ★ **这是固定 2 倍关系**，不随"差异程度"变化——不存在"差异越大消耗越多"这回事。

### 九种极性

| 极性名 | 中文含义 |
|---|---|
| Vazarin | 防御 |
| Naramon | 战术 |
| Madurai | 攻击 |
| Zenurik | 威力 |
| Penjaga | 预置 |
| Unairu | 守护 |
| Umbra | 暗影 |
| Universal | 万能（Umbra 除外） |
| Aura | 光环 |

### ★ 常见误解（否定事实）

- **极性与"属性"无关**：极性只影响 Mod 容量消耗，不影响生命、护盾、伤害等任何属性。
- **不存在"极性符文"这种物品**——极性是槽位自带的符号，不是可安装的符文。
- **普通 Forma 无法添加 Umbra 或万能极性**（需专用 Forma）。

> **来源**：`wiki.warframe.com/w/Polarity`、`wiki.warframe.com/w/Polarization`

## 三、Mod 容量与「土豆」

### Orokin Reactor / Orokin Catalyst 的真实作用

| 物品 | 俗称 | 作用 | 适用 |
|---|---|---|---|
| **Orokin Reactor** | **蓝土豆** | 使 **Mod 容量翻倍** | 战甲、Archwing、同伴 |
| **Orokin Catalyst** | **黄土豆** | 使 **Mod 容量翻倍** | 武器 |

- 满级（Rank 30）时，**Orokin Reactor / Catalyst 额外提供 30 点容量**（即容量上限从 30 提升到 60）。
- 在用 Forma 极化之前，**通常建议先上土豆**——额外的 Mod 容量比逐槽划分消耗更高效。

### ★ 常见误解（否定事实）

- **蓝土豆 / 黄土豆与伤害、暴击率、技能效果毫无关系。** 它们**唯一**的作用是**翻倍 Mod 容量**，让你能装更多或更强的 Mod。
- 它们**不是**"提升基础属性"或"激活特殊能力"的道具。
- 用 Forma 要达到同样的容量收益，需要极化 **4 个槽位**（消耗 4 个 Forma），且每次都要重新练级——**所以土豆的性价比远高于 Forma**。

> **来源**：`wiki.warframe.com/w/Orokin_Reactor`、`wiki.warframe.com/w/Orokin_Catalyst`、`wiki.warframe.com/w/Polarization`

## 四、紫卡（Riven Mod）与倾向度（Disposition）

### 紫卡的基本特性

- 紫卡是为**主武器 / 副武器 / 近战 / Archgun / 机械武器**准备的特殊 Mod。
- **完全独一无二**：即使属性种类相同，数值也不同。
- 需要玩家**完成指定挑战**才会揭示其武器归属与属性。
- 携带 **2 或 3 条加成**；**可以带一条负面属性**（负面会大幅提升正面加成强度）。
- 极性可为 Madurai / Naramon / Vazarin 中任意一种。
- 有**独立的段位要求**，范围 **8 到 16**。
- 可用**赤毒（Kuva）重roll 加成**（但不能改武器或极性）。
- **一把武器只能装一张紫卡**（同类紫卡不能同时装备）。
- 初始 15 个紫卡槽位，商城 60 铂金买 3 个，最多 180 个；达到 MR 30 额外 +30，总计 210。

### ★ 倾向度（Disposition）机制

> 游戏内描述：「Modifies the performance of an equipped Riven mod. **More dots indicates stronger stats.**」

**倾向度是一个「属性乘数（stat multiplier）」**，由系统根据高段位玩家的武器使用率与武器"强度"内部排名综合给出。

**倾向度决定每把武器可用属性的数值范围**，取值 **0.5 到 1.55**，游戏内简化为 5 档：

| 图示 | 数值范围 | 档位 | 含义 |
|---|---|---|---|
| ●●●●● | 1.31–1.55 | **Strong（强）** | 分配给**最少被使用**的武器，紫卡属性**最大** |
| ●●●●○ | 1.11–1.3 | — | 不太热门的武器，属性**高于平均** |
| ●●●○○ | 0.9–1.1 | **Neutral（中性）** | 使用率平均的武器，属性**平均** |
| ●●○○○ | 0.7–0.89 | — | 略热门武器，属性**低于平均** |
| ●○○○○ | 0.5–0.69 | **Faint（弱）** | 分配给**最常使用**的武器，属性**最收敛（最小）** |

> **所有新发布的武器初始倾向度都是 ●○○○○（0.5–0.69）。**

### 属性数值计算公式

> 紫卡的实际属性数值在**基础值的 90% 到 110%** 之间随机选取，**再乘以该武器的紫卡倾向度**，最后乘以对应的加成/减益权重。

权重表：

| 属性构成 | 加成权重 | 减益权重 |
|---|---|---|
| 2 加成，0 减益 | 0.99 | 0 |
| 2 加成，1 减益 | 1.2375 | −0.495 |
| 3 加成，0 减益 | 0.75 | 0 |
| 3 加成，1 减益 | 0.9375 | −0.75 |

### 倾向度的其他规则

- **倾向度不一定在同武器的所有变体间共享**。例：Telos Boltor 与其 Prime 变体共享 1.20，但普通 Boltor 是 1.30。
- **模块化武器**（Modular Weapons）的倾向度绑定**主组件**：Zaw 绑 Strike，Kitgun 绑 Chamber（副武器与主武器版本可能不同）。
- **倾向度每 3 个月调整一次**，与每次新的 Prime Access 同步。若某武器倾向度被调整，**已揭示的紫卡属性会自动调整**以匹配新倾向度。
- 可在军械库的 **Upgrade 标签页**查看某武器的倾向度。

### ★ 常见误解（否定事实）

- **倾向度影响的是属性「数值高低」，不是属性「出现的概率」。** 它是公式里的**乘数**，直接缩放最终数值。
- 属性**是否出现**由 2–4 条随机抽取决定，**与倾向度无关**。
- 倾向度**不只是"稀有度"**，它是使用热度 + 武器强度的综合结果。

> **来源**：`wiki.warframe.com/w/Riven_Mods`

## 五、钢铁之路（The Steel Path）

### 解锁条件

- 必须**完成「新战争」之前所有可访问的星图节点**（相连星图）。
- **例外节点**（无需完成）：阋神星的 Mutalist Alad V 与 Jordas Golem 刺杀；天王星的 Brutus。
- **无需**解锁或完成 Zariman Ten Zero、阿尔布雷希特实验室、Höllvania 的任何任务。
- 需完成特定剧情锁定节点（Lua 与 Kuva Fortress 全部节点等）。
- **在任何中继站与 Teshin 对话**，选择「Steel Path?」，满足条件后即可解锁；解锁后星图右侧出现开关。
- **Duviri 额外条件**：需完成「Duviri 悖论」任务，并在普通模式完成 The Duviri Experience / The Lone Story / The Circuit 三个基础节点（**不需要**完成 Isleweaver）。

### ★ 敌人数值加成（核心数值）

| 项目 | 数值 |
|---|---|
| **敌人等级** | **+100**（Archwing / Railjack 仅 **+50**） |
| **敌人生命** | **250%**（即额外 +150%，总计 **2.5 倍**） |
| **敌人护盾** | **250%**（即额外 +150%，总计 **2.5 倍**） |
| **敌人护甲** | **不增加**（自 Hotfix 37.0.4 起） |

> ⚠️ 钢铁之路护盾现为 **2.5 倍**，取代了旧版的 6.25 倍（旧版护盾倍数曾被意外双重叠加）。

### 掉率加成

| 项目 | 加成 |
|---|---|
| 资源掉落几率 | **+100%** |
| Mod 掉落几率 | **+100%**（Railjack **除外**） |

- 这些加成与「真大师之泉」祝福、资源/Mod 掉落加成器、暗区加成**加算叠加**。

### 特殊场景差异

- **Archwing / Empyrean（Railjack）**：等级仅 **+50**；例外：Grineer Sealab 水下 Archwing 场景仍 **+100**。
- **Duviri**：等级仅 **+20**，且**生命/护盾不变**；Orowyrm Boss 战有额外机制。但 **The Undercroft / The Circuit / Isleweaver 使用默认钢铁加成**（+100 级、生命护盾 250%）。
- **夜灵（Eidolon）**：Teralyst → **110 级**，Gantulyst → **120 级**，Hydrolyst → **130 级**。
- **赏金任务**：起始等级 **100**，需**段位 10** 才能进入。

### 钢铁精华（Steel Essence）获取

| 来源 | 数量 |
|---|---|
| 每日 6 个入侵任务（Incursions） | 每个 **5** 个（不受加成器影响） |
| 追猎者（Acolyte） | 保证 **2** 个 |
| 夜灵三使 | 保证 **1** 个 |
| 打开虚空裂缝遗物 | **1** 个 |
| 清除 Empyrean 任务 | **2** 个 |
| Zariman / 实验室 / Höllvania 赏金钢铁变体 | 额外 **1** 个 |
| Duviri 三个节点 | **5** 个 |
| 完整清除一颗星球全部节点 | **25** 个 |

### 追猎者（Acolytes）刷新机制

- 可在**除** Archwing、刺杀、Ascension、Duviri、Empyrean **之外**的任意钢铁之路任务生成。
- 每次任务可生成**多个**，间隔约 **3–7 分钟**（生存任务平均约 **4 分 30 秒**）。
- 非无尽任务中**最多 3 个**。
- **不会**由 Specters（幽魂）或 On Call Crew（随叫船员）的击杀生成。
- 被追猎者击倒时它会逃脱，**玩家无法获得钢铁精华**。

### ★ 常见误解（否定事实）

- **钢铁之路敌人等级是 +100，不是 +10 或 +30。** 这是数量级差异。
- **钢铁之路敌人护甲不增加**（旧版会，现已移除）。
- **钢铁之路不适用于**：梦魇模式、集团、入侵。
- 钢铁之路上的**接合点无任务要求**，相邻节点清除后即可进入。

> **来源**：`wiki.warframe.com/w/The_Steel_Path`

## 六、常见机制误解速查表

> 本表专为纠正高频错误认知而设。当用户问到以下问题时，**以下为准确答案**：

| 用户可能问 | ★ 准确答案 |
|---|---|
| 极化有什么用？ | 改变 Mod 槽位的**极性**，提升容量效率。**不给额外槽位**。 |
| 极化等级是什么？ | **不存在这个概念**。装备上的星标只是"已用 Forma 数量"。 |
| 极化后装备会怎样？ | **等级重置为 0**，需重新练级；**重练不给段位经验**。 |
| 极化会改基础属性吗？ | **不会**。只影响 Mod 容量效率。 |
| 蓝土豆 / 黄土豆有什么用？ | **唯一作用是翻倍 Mod 容量**（满级 +30 容量）。**与伤害、技能无关**。 |
| 紫卡倾向度影响什么？ | 影响属性**数值高低**（是乘数），**不影响出现概率**。 |
| 倾向度范围？ | **0.5–1.55**，5 档；新武器初始 **0.5–0.69**。 |
| 倾向度多久变一次？ | **每 3 个月**，随 Prime Access 更新；已开紫卡数值**自动调整**。 |
| 钢铁之路敌人等级？ | **+100**（Archwing/Railjack 为 +50）。 |
| 钢铁之路生命/护盾？ | 均为 **250%（2.5 倍）**；**护甲不增加**。 |
| 极性匹配/不匹配？ | 匹配**减半**、不匹配**翻倍**，固定 **2 倍**关系。 |
| 存在"极性符文"吗？ | **不存在**。极性是槽位自带符号，不是可安装物品。 |
