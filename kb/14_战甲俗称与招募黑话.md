## 一、易混淆澄清（高频误答点）

### 花甲 / 花P / 花 ＝ Wisp（**不是** Garuda）

- **结论**：喊「花甲 / 花P / 花」= **Wisp**。
- **词源**：Wisp 的 1 技能在地面放置储能枢纽（活力 / 日炎 / 电击脉冲），模型插在地上形似盆栽「种花」，全社区统称花甲 / 花P。
- **⚠️ 易错**：不要答成 Garuda。Garuda 是「血妈」（下一条）。

### 血妈 / 血P ＝ Garuda（**不叫**「鸟妹」）

- **结论**：Garuda = **血妈 / 血P**。偶尔称「爪妹」「割腕女」。
- **词源**：神话原型是金翅鸟（迦楼罗），但实机机制完全围绕自残扣血、割腕回蓝、吸血祭祀、挂全屏流血。为避免与真正的鸟类战甲 **Zephyr（鸟姐 / 鸟妹）** 混淆，社区统一叫「血妈」。
- **⚠️ 易错**：「鸟妹 / 鸟姐」指 Zephyr，不是 Garuda。

### 猫 / 猫P ＝ Khora（Valkyr 是「老猫甲」）

- **结论**：招募频道打「猫」或「猫P」，**默认 100% 指 Khora**（荒野猎手）。
- **词源**：Khora 真正随身携带一只狯犽（猫使魔），是**现任唯一真猫甲**；招牌是绞杀穹顶聚怪 + 抽鞭子输出。
- **代际差别**：Valkyr（瓦喵 / 女武神）因猫耳轮廓与「受击猫着地」被动，是**老一代猫甲**；现在只说「瓦喵」或「Valkyr」，不再简称「猫」。

### 奶妈 / 奶P ＝ Trinity；奶爸 ＝ Oberon

- **奶妈 / 奶P ＝ Trinity**：团队续航核心，2 技能吸蓝、4 技能全图回血回盾减伤；「T妈」同义。
- **奶爸 ＝ Oberon**：持续群体回血 + 辐射草毯免控；外号还有「驴王」「鹿」（原版头部像驴、P 版像鹿角）。
- **⚠️ 易错**：两者是不同战甲，不要混答。

### 电 / 电P ＝ Volt；高 / 高P ＝ Gauss（两个「跑男」的代际差别）

- **电 / 电P ＝ Volt（伏特）**：**老一代「跑男」**。2 技能给全队极速奔跑（能带全队一起飙车），三傻破盾与圣殿清图必备劳模。
- **高 / 高P ＝ Gauss（高斯）**：**新一代「跑男」**，也叫「音速小子」「马赫」。单兵极速冲撞与动能蓄力，真正意义上的竞速甲。
- **⚠️ 易错**：如今单独喊「跑男」多指 Gauss；但在三傻 / 圣殿这类传统语境里「电」才是 Volt。两个都别答错阵容位。

### 「明神」的双面含义（Limbo）

- **基础叫法**：Limbo = **小明 / 明神 / 明P**（英文首字母联想成「小明」）。
- **双面含义**：「明神」既是**对高阶控场大神的赞誉**，也常用于**反讽**——大范围 4 技能「大灾变」封锁战场、害队友打不到怪捡不到道具的「搞心态明神」。听到「明神」需结合语境判断褒贬。

### 其他常被问到的梗源（一句话）

- **鸭梨 ＝ Yareli**：英文名读音空耳谐音；踩水滑板、二次元萌系。
- **茶妹 / 普洱茶 / 茶P ＝ Protea**：读音谐音「普罗提亚 → 普洱茶」；炮台、补给箱、时间倒流。
- **肥仔 / 肥宅 / 肥P ＝ Grendel**：外观圆滚 + 大口吞人、肉球滚地。
- **潘森 ＝ Styanax**：斯巴达盾矛造型与投掷长矛雨，神似《英雄联盟》的潘森。
- **暖气片 ＝ Qorvex**：厚重水泥铅板 + 辐射脉冲石柱，造型神似铸铁暖气片。
- **赛马娘 / 赛马甲 ＝ Dagath**：无头女骑士，4 技能召唤虚空烈马踏平全场。
- **药水哥 / 炼金 ＝ Lavos**：双臂缠蛇、无能量条（纯 CD），长按技能调配复合元素。
- **弱鸡 / 洛基 ＝ Loki**：「弱鸡」是 Loki 谐音；老牌脆皮、缺硬免伤，自嘲口癖。
- **扣妹 ＝ Koumei**：日文罗马音直接空耳；摇骰子赌运。
- **老九 / 昆西 ＝ Cyte-09**：编号末尾「09」直接叫「老九」；剧情原型是 1999 的狙击手昆西。

## 四、招募频道车队组合

> 社区喊话常把所需战甲用**单字连缀**，如「1=3 来电牛奶龙」。以下是最常见的四类车队。

### 4.1 三傻大狩猎（夜灵平原）：**电 / 牛 / 奶 / 龙**

- **喊话范例**：「三傻 1=3 来电牛奶龙」——**三傻** = 夜灵平原的三只使徒（Teralyst / Gantulyst / Hydrolyst）。
- **电（Volt）**：立电盾增幅指挥官虚空伤害，快速打碎夜灵护盾。
- **牛（Rhino）**：战吼给全队巨额增伤。
- **奶（Trinity）**：保气球（诱饵）不爆，维持全队生命。
- **龙（Chroma）**：高倍率增伤，一枪打爆夜灵关节。

### 4.2 钢铁生存（材料 / 资源队）：**摸 / 水 / 奶 / 加速**

- **喊话范例**：「钢铁生存 1=3 来摸水奶奶加速」（社区口语写法；**实际所需四职以下列为准**）。
- **摸（Nekros）**：3 技能亵渎摸额外掉落。
- **水（Hydroid）**：4 技能触手抓怪，提高掉落与剥甲。
- **奶（Trinity）**：保障全队能量充沛与生命回复。
- **加速（Nova，加速娃）**：压低技能强度让怪物全速冲进包围圈，提升清怪效率。

### 4.3 圣殿经验队（ESO，精英圣殿突袭）：**毒 / 电 / 奶**

- **喊话范例**：「圣殿 1=3 来毒电奶」。（个别频道也写作 ESD 队，均指圣殿经验队。）
- **毒（Saryn）** 与 **电（Volt）**：轮流全图清场打积分。
- **奶（Trinity）**：提供永动能量源。

### 4.4 高难挂机 / 执政官通用队：**花 / 茶 / 牛 / 猴**

- **喊话范例**：「执政官 / 高波 1=3 来花、茶、牛、猴」。
- **花（Wisp）**：全图种花加血量与狂暴攻速。
- **茶（Protea）**：无限蓝量弹药补给 + 自动炮台压制。
- **牛（Rhino）**：全体战吼大幅拉高 DPS。
- **猴（Wukong）**：高容错机动输出。

### 4.5 单字速记

- **三傻队** = 电 牛 奶 龙（Volt / Rhino / Trinity / Chroma）
- **钢铁材料队** = 摸 水 奶 加速（Nekros / Hydroid / Trinity / Nova）
- **圣殿经验队** = 毒 电 奶（Saryn / Volt / Trinity）
- **高难挂机队** = 花 茶 牛 猴（Wisp / Protea / Rhino / Wukong）
