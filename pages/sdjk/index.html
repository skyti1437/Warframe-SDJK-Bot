概览

机器人当前状态与需要处理的事项

需要处理

    数据

    各数据快照是否新鲜；过期的卡片会提示或不再展示

    数据新鲜度

    刷新会从社区快照（默认本项目公开仓 bot-data，可在「设置 → 社区数据地址」换成自己的）拉元素加成、言录使货单、仲裁评级、奸商到访历史、紫卡倾向；只有比本地新的才会替换。
    数据状态快照时间说明

    社区快照通道

    本机最近一次检查每份社区快照的结论：走的哪条通道、有没有采用、为什么没采用。插件重启后清空，下次检查时重新记录。
    数据结论通道数据时间检查时间说明

    有效数据账本

    逐份对照「运行目录副本」与「随包种子」，说明插件此刻实际读到的是哪一份。只列正在生效或需要处理的；账本只读，不会改名、删除或写入任何数据文件。
    文件实际采用运行副本时间种子时间结论建议

    数据登记

    每份随包数据文件的来源、生产器与判定方式。「不按时间判」= 稳定表，上游变了才重建；「来源未确认」= 登记表里查不到来源。
    分组文件判定方式状态内容时间说明

    推送与订阅

    推送守护运行状态；按群管理「蹲」订阅与推送开关

    推送守护

    蹲订阅

    群推送关闭时，该群的订阅暂停推送但不会被删除；连续发送失败的群会被暂停推送（可点「恢复推送」，或到点自动重试）。删除订阅要点两次确认。

    设置

    与 AstrBot 插件配置页同一份配置；标「即时生效」的保存后马上用上，标「需重载」的要在后台重载插件

    依赖与资源

    插件运行需要的 Python 包；字体在「外观」页

    Python 依赖

    包要求已安装状态
    按插件的 requirements.txt 安装，走 AstrBot 自己的 pip 设置（镜像源、版本约束）；装完需重载插件

    外观

    图片卡片的配色、背景图、角标与字体（保存后新出的卡片立即生效，不用重载）

    配色

    1. 先挑一个预设，或者在下面逐项改颜色；右边的预览会在你停手约半秒后自动刷新（用的是机器人真实的出图程序）。
    2. 不知道某一项管哪里？点它旁边的 定位：预览会把这一项临时染成品红，一眼看出它改的是卡片哪个部分。
    3. 「高级」里是表示类别的颜色（裂隙青、钢铁红、MOD 紫…），改了会影响一眼认出类别，建议保持区分度。
    4. 满意后点底部保存主题；随时可以点「Orokin（默认）」恢复原样。
    高级：类别色
    背景图与角标
    背景压暗 越大背景越暗、文字越清楚
    面板不透明度 有背景图时生效；1 = 不透明
    显示在页脚右侧水印左边（建议透明底 PNG）
    预览
    主题有改动未保存

    字体

    —
    「自动」= 完整字库 → 你导入的字体 → 随包子集 → 系统字体，取第一个可用的
    字体库
    文件字体名来源大小中文
    添加字体
    Noto Sans CJK 完整版：随包只带常用 6763 字，生僻字会显示为方块
    不超过 64 MB；必须包含常用汉字，否则卡片会出方块，不会导入
    导入的字体保存在插件数据目录（plugin_data/…/fonts），插件更新不会丢。请只导入你有权使用的字体。
